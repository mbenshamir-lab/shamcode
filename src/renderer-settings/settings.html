Dictée vocale (micro)

Affiche un bouton micro dans la zone de saisie : tu parles, l'IA transcrit puis résume l'idée principale dans le champ. Transcription locale (Whisper) — le modèle (~75 Mo) se télécharge à la première dictée. Désactivé par défaut.

Le modèle choisi est utilisé pour les prochaines dictées. « Télécharger » le prépare maintenant ; sinon il se télécharge à la première dictée. « Précis » comprend mieux le vocabulaire technique, au prix d'une transcription plus lente.

LSP (lsp_hover / lsp_definition / lsp_references)

Connecte l'agent à un Language Server pour obtenir les types, la définition et les usages d'un symbole. Désactivé par défaut — nécessite un serveur installé.

Installer : npm install -g typescript-language-server typescript

Installer : pip install python-lsp-server

Installer : go install golang.org/x/tools/gopls@latest
