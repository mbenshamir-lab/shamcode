# Code de conduite / Code of Conduct

Sois respectueux, constructif et bienveillant envers toutes les personnes qui participent au projet.
Les critiques portent sur le code et les idées, jamais sur les personnes. Harcèlement, insultes et
discriminations ne sont pas tolérés ; le mainteneur peut modérer ou supprimer tout contenu, et
bloquer les contributeurs concernés.

Be respectful, constructive and welcoming. Critique code and ideas, never people. Harassment,
insults and discrimination are not tolerated; the maintainer may moderate or remove any content
and block offending contributors.
